# nginx-lab

Laboratorio de configuración y pruebas con Nginx.

## Descripción

Este repositorio contiene ejemplos y configuraciones para experimentar con Nginx como servidor web y proxy inverso.

## Contenido

- Configuraciones de servidor básicas
- Ejemplos de proxy inverso
- Configuraciones de balanceo de carga

## Uso

Consulta cada directorio para instrucciones específicas de configuración.
